PUBLISHING ON GITHUB PAGES
--------------------------
1. Open the repository:
   https://github.com/danafouras/danafouras.github.io

2. Choose "Add file" → "Upload files".

3. Upload index.html and the complete assets folder.

4. Commit the changes to the main branch.

5. GitHub Pages should already be configured to:
   Branch: main
   Folder: / (root)

6. The site should appear at:
   https://danafouras.github.io

GitHub notes that publication can take up to around 10 minutes after changes are pushed.

CONTENT NOTE
------------
The site deliberately keeps future Australian activity described as developing/planned,
rather than presenting unconfirmed dates or funding outcomes as facts.

The website uses links to Russell Maliphant Dance Company's existing work and Creative
Intensive pages. These are external links and open in a new browser tab.
